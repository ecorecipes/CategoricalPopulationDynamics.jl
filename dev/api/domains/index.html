Domain Types

Domain types describe the state spaces associated with life stages in a projection net. A domain can be continuous (for integral projection models) or discrete (for matrix population models).

CategoricalPopulationDynamics.ContinuousProjectionDomain — Type
ContinuousProjectionDomain{T<:Real}

Continuous state variable domain discretized via the midpoint rule.

source
CategoricalPopulationDynamics.DiscreteProjectionDomain — Type
DiscreteProjectionDomain

Discrete state variable with a fixed number of classes.

CategoricalPopulationDynamics.TransitionSpec — Type
TransitionSpec

Associates a transition name with its data (kernel function, matrix, or parameters).

source
using CategoricalPopulationDynamics

continuous_domain = ContinuousProjectionDomain(0.0, 1.0, 4)
discrete_domain = DiscreteProjectionDomain([:seed, :adult])
spec = TransitionSpec(:survival, 0.85)

(
    meshpoints = meshpoints(continuous_domain),
    step = step_size(continuous_domain),
    n_discrete = n_meshpoints(discrete_domain),
    bounds = bounds(continuous_domain),
    transition_name = spec.name,
)
(meshpoints = [0.125, 0.375, 0.625, 0.875], step = 0.25, n_discrete = 2, bounds = [0.0, 0.25, 0.5, 0.75, 1.0], transition_name = :survival)
