Composition

Compositional model construction assembles complex population models from simpler components. Models are composed via undirected wiring diagrams using the structured cospan machinery provided by Catlab.jl.

CategoricalPopulationDynamics.ProjectionSharer — Type
ProjectionSharer{T<:Real}

An undirected open system wrapping a transition matrix.

Ports represent state variables shared with other sharers. When composed via oapply, sharers at the same junction sum their matrix contributions (additive operadic algebra).

Fields

  • nports: number of exposed ports (state variables)
  • nstates: internal state dimension (mesh size)
  • matrix: the nstates × nstates transition matrix
  • portmap: maps port indices to internal state indices

Catlab.WiringDiagrams.WiringDiagramAlgebras.oapply — Function
oapply(d::AbstractUWD, sharers::Vector{ProjectionSharer{T}})

Compose ProjectionSharers according to an undirected wiring diagram.

For projection models, composition is additive: sub-kernels sharing the same state variables sum their contributions.

Each box in the UWD corresponds to a sharer; junctions identify shared state variables. All sharers must have the same nstates.
